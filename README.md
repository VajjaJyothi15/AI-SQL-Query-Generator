# AI SQL Assistant

AI SQL Assistant is a Flask-based web application that converts natural language questions into SQL queries using the Groq API.

# Features
Natural Language to SQL
Multiple SQL Dialects
Query Explanation
Download SQL Files
Modern Developer-Friendly UI
# Tech Stack
Python
Flask
Groq API
HTML
CSS
# Run
pip install -r requirements.txt
python app.py

# Add your Groq API key in .env:

GROQ_API_KEY=YOUR_API_KEY
